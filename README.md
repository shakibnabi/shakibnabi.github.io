# Shakib Nabi — Portfolio (version 2)

Modern Next.js rebuild of the personal site.

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- GSAP (`@gsap/react`, ScrollTrigger)
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
